# Тесты приложения

Проверяют расчетную часть `app_final.py` (всё, что находится выше блока интерфейса `# ============ UI ============`)
и сами файлы данных `financials_ru.csv` и `macro_ru.csv`. Сеть, браузер и Streamlit не нужны.

## Запуск

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты сами находят `app_final.py`: сначала рядом с файлом `conftest.py`, затем в родительской и в текущей папке
и в их подпапках. Подойдет любая раскладка, например:

- `app_final.py`, `pytest.ini` и папка `tests` в одной папке (рекомендуется);
- или все файлы тестов лежат прямо рядом с `app_final.py`.

В начале вывода `pytest` печатает строку «Тестируемый файл: …» с найденным путем. Если файл не найден, запуск
остановится с понятным сообщением. Путь можно задать вручную в переменной окружения `APP_FINAL_PATH`.
Файлы данных `financials_ru.csv` и `macro_ru.csv` должны лежать в одной папке с `app_final.py`.

Один файл: `pytest test_growth.py`. Подробный вывод: `pytest -v`.

## Что где проверяется

| Файл | Что проверяет |
|---|---|
| `test_growth.py` | рост г/г, CAGR, «светофор» |
| `test_profitability.py` | таблица по годам, маржа, единицы |
| `test_adjustments.py` | пересчет $ → ₽, инфляция, `macro_ru.csv` |
| `test_price_metrics.py` | волатильность, просадка, скользящие средние |
| `test_market.py` | капитализация, P/S, P/E, дивиденды, payout |
| `test_export.py` | CSV и Excel, таблицы выгрузки |
| `test_validation.py` | проверка файла данных на испорченных примерах |
| `test_comparison.py` | режим сравнения, разбор тикеров, данные yfinance |
| `test_data_files.py` | реальные файлы данных: опечатки, единицы, источники, оценки |

## После обновления данных

Запустите `pytest tests/test_data_files.py`: тест подскажет строку файла, где найдена проблема
(ошибка, дубликат, смешанные единицы, расчетное значение без комментария и т.д.).

## Ограничения

Тесты используют условные цены и условные ответы yfinance. Реальные запросы к Мосбирже и Yahoo
в них не проверяются: это делается запуском самого приложения.
