# Тесты приложения

Проверяют расчётную часть (пакет `salesanalyzer`: `core`, `data_sources`, `services`) и сами файлы данных
`financials_ru.csv` и `macro_ru.csv`. Интерфейс (`salesanalyzer/ui`), сеть и браузер не запускаются:
`streamlit` (а при необходимости `yfinance`, `requests`, `plotly`) подменяется заглушкой.

## Запуск

```bash
pip install pytest pandas numpy openpyxl
pytest
```

Из папки проекта (там, где лежит папка `salesanalyzer`). Один файл: `pytest tests/test_growth.py`.
Подробный вывод: `pytest -v`. Только проверка данных: `pytest -k data_files`.

Тесты сами находят папку с пакетом `salesanalyzer`: рядом с `conftest.py`, в родительской и в текущей папке
и в их подпапках. Подойдёт и раскладка «папка `tests` внутри проекта», и раскладка «файлы тестов лежат прямо в папке проекта».
В начале вывода печатается найденный корень проекта. Если пакет не найден, запуск остановится с понятным сообщением;
путь можно задать переменной окружения `SALESANALYZER_ROOT` (PowerShell: `$env:SALESANALYZER_ROOT = "C:\путь\к\проекту"`).

## Что где проверяется

| Файл | Что проверяет |
|---|---|
| `test_growth.py` | рост г/г, CAGR, «светофор» |
| `test_profitability.py` | таблица по годам, маржа, единицы |
| `test_adjustments.py` | пересчёт $ → ₽, инфляция, `macro_ru.csv` |
| `test_price_metrics.py` | волатильность, просадка, скользящие средние |
| `test_market.py` | капитализация, P/S, P/E, дивиденды, payout |
| `test_export.py` | CSV и Excel, таблицы выгрузки |
| `test_validation.py` | проверка файла данных на испорченных примерах |
| `test_comparison.py` | режим сравнения, разбор тикеров, данные yfinance |
| `test_data_files.py` | реальные файлы данных: опечатки, единицы, источники, оценки |
| `test_forecast.py` | прогноз показателей: методы, сценарии, проверка на прошлом, надёжность |
| `test_reliability.py` | повторные попытки, понятные ошибки Мосбиржи и Yahoo (на заглушках), совместимость с версиями Streamlit |

В `conftest.py` фикстура `app` собирает все расчётные функции из модулей пакета в один объект
(`app.add_growth`, `app.market_stats_ru` и т.д.), а фикстура `cfg` даёт доступ к `config`, через который тесты подменяют пути к файлам.

## После обновления данных

Запустите `pytest -k data_files`: тест подскажет строку файла, где найдена проблема
(ошибка, дубликат, смешанные единицы, расчётное значение без комментария и т.д.).

## Ограничения

Тесты используют условные цены и условные ответы yfinance. Реальные запросы к Мосбирже и Yahoo
в них не проверяются: это делается запуском самого приложения.
